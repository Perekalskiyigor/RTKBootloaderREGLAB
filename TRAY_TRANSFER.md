# Перекладка: 61 исходная ячейка → группы по 4 готовых ячейки

Файл `WORK_FILE_TRAY_TRANSFER.py` использует имена счётчиков, OPC-узлы,
Modbus-адреса и команды из `WORK_FILE_21_07.py`. Изменения пояснены в коде.
Столы, прошивка, камера, 1С и БД не запускаются; ненужные выходы — заглушки.

```bat
python WORK_FILE_TRAY_TRANSFER.py
```

Зависимости те же: `pymodbus==2.5.3`, `opcua==0.98.13`.
Адреса оборудования и лимиты находятся в начале файла.

## Обмен с ПЛК

Все перечисленные OPC-переменные находятся в `Application.UserInterface`:

| Узел | Направление | Назначение |
|---|---|---|
| `OPC_start_RTK` | ПЛК → Python | Разрешение работы |
| `OPC_pause_RTK` | ПЛК → Python | Пауза перед следующей командой |
| **`OPC_ready_tray_full`** | **Python ↔ ПЛК** | **Python выставляет True: четыре ячейки заполнены; ПЛК сбрасывает False: предоставлены пустые ячейки** |
| `OPC_finish_order` | ПЛК → Python | Закончить после текущей платы |
| `OPC_restart_RTK` | ПЛК → Python | Остановить цикл с фиксацией ошибки |

`OPC_ready_tray_full` — BOOL с разрешением чтения и записи по OPC.
NodeId: `ns=2;s=Application.UserInterface.OPC_ready_tray_full`.
`OPC_do_next_tara` относится к горячей замене исходной тары;
программа перекладки его не читает и не записывает.

Последовательность:

1. Исходная тара заполнена, готовые ячейки пустые; включить `OPC_start_RTK`.
2. `210`: взять из исходной ячейки `Cell1 + 1`; `241`: положить в `Cell2 + 1`.
3. После подтверждения четвёртой укладки Python выставляет
   `OPC_ready_tray_full = True` и больше не берёт платы.
4. ПЛК/оператор предоставляет пустые ячейки и сбрасывает `OPC_ready_tray_full = False`.
5. Python видит сброс и обнуляет **только `Cell2 = 0`**. `Cell1` сохраняется.
   Флаг True отправляется однократно на каждую заполненную группу,
   поэтому сброс от ПЛК не перезаписывается.
6. Цикл продолжается с очередной исходной ячейки. После ячейки 61 завершается:
   получится 15 групп по 4 и одна плата в последней группе. На неполной
   последней группе флаг заполнения не выставляется; `OPC_end_order = False`.

Раннее подтверждение замены не запоминается. Общий счётчик переложенных плат
отображается в `OPC_success_count`, остаток исходной тары — в `OPC_cnt_newBoard`.

Modbus: команда — адрес 4, ответ — 5, тара — 6, ячейка — 8.
Тара 1 — исходная, тара 2 — готовая. Адресация как в исходнике.
Выходы столов 0, 2, 10, 12, 18, 20, 24, 25 равны нулю.

Пауза действует между командами, не прерывает движение. При ошибке `404`,
таймауте или потере OPC цикл останавливается; переподключение OPC не повторяет
движения. Лог — `TrayTransfer.log`. После завершения программа сохраняет OPC-обмен
до Ctrl+C. Счётчики не сохраняются на диск: новый запуск предполагает полную
исходную тару, пустые готовые ячейки и пустой захват.
